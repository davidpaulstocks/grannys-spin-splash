# Art prompts for worlds 7 to 16 (written 2026-11-28)

Everything David needs to paint for the ten new worlds, ready to paste into Nano Banana. For each
picture: attach the reference image named, paste the template, and add the world's own lines where
marked. **The session must send David the reference image file with each prompt** (he does not go
looking in folders).

Per world there are three paintings: a wide backdrop, a tall backdrop, and one sheet of six visitors.
There are also four sheets of six new guns.

## What to check on each painting

- Backdrops: the plain wall takes up roughly the middle half of the picture. If it is a small patch with
  lots of scenery, regenerate.
- Sheets: exactly six, none touching, all guns nozzle-right. An extra or a left-facing one is fine: say
  so and the cutter will skip or flip it.
